How do I know the page is not styling the banner

Open the consent monitor and use Inspect banner styles. It reads the computed background and text colour of every button inside the shadow root and prints them in the log, together with the font the host inherits from the page. Compare those values with the admin configuration.

What exactly is isolated

Shadow DOM already blocks page selectors. On top of that, html and body declare no inherited property, all custom properties live on .page instead of :root, and no selector names the banner host. So the banner inherits browser defaults only.

Why are categories listed instead of fixed names

Usercentrics models consent per data processing service, and category slugs come from the configuration. The monitor groups the services returned by getServicesBaseInfo by categorySlug, so it shows whatever this settings id actually has.

Why are the embeds blocked before consent

The Smart Data Protector blocks known third party embeds by matching their source. It only works if the matching service, for example Google Maps or YouTube Video, is present in the configuration.
